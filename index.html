Getting the KMZ into DJI Fly
  1. In DJI Fly, create any throwaway waypoint mission so the app makes a mission folder.
  2. Connect the RC / phone and open Android/data/dji.go.v5/files/waypoint/.
  3. Each mission is a folder named with a UUID containing one <same-UUID>.kmz.
  4. Rename the exported file to that UUID and overwrite the one inside the folder.
  5. Restart DJI Fly. The mission appears in the waypoint list.

On iOS the path is DJI Fly/wayline_mission/. DJI Fly caps a mission at 200 waypoints — longer plans are exported as numbered parts to fly back to back.
